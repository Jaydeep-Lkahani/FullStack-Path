# FullStack Path

A learning site that takes you from fundamentals to job-ready in React, Node.js and Next.js. Built with Next.js (App Router), TypeScript, Tailwind and MDX.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run lint && npm run typecheck
npm run check:content   # validate lesson frontmatter
npm run check:videos    # verify every YouTube link still exists
```

Lessons live in `content/<module>/<lesson>.mdx`. The roadmap (phases and modules) is defined in `src/lib/roadmap.ts`. See `PENDING.md` for the plan and status.
